# SubNest Android 0.1.0-preview.4

- 新增待办总览，可进入今日、逾期、近期续费和空车位筛选。
- 会员管理默认显示车位，账号资料、分享链接、经营概览通过标签查看；密码仅在主动复制时读取。
- 增加车位编辑与续费，支持本期总收费、周期、日期、备注及已收/待收状态；保存失败保留输入并显示错误。
- 支持验证码链接读取、生成、复制和撤销确认；邮箱链接沿用已配置的邮箱、文件夹与查看时长。
- 服务名称优先展示，不同币种分别显示。

验证：Android 构建、Lint、12 项数据层测试通过；API 37 模拟器完整流程通过，覆盖登录、筛选与重建恢复、订阅续费、保存 15 元且已收、关闭并重新读取、退出登录。所有写入测试仅使用隔离的本地测试库。

配套网页 v0.3.124 重做仪表盘、订阅和会员共享核心工作区。

仍为 debug 签名预览版，可覆盖此前同签名预览版。订阅新增编辑、邮箱基础配置等操作仍需网页版，并非完整功能对等的正式客户端。无消息推送。

基于 Nodyssey，GPL-3.0；源码及构建说明见本仓库。
