# 0.1.0-preview.1

独立 Android 原生预览客户端，底部入口为订阅、会员共享、我的。

- 登录、双因素验证接口、加密会话与退出清理。
- 搜索编号或账号，完整平台选择，今日、7 天内、逾期和空位筛选。
- 订阅续费确认、共享账号车位只读查看。
- 系统深浅主题、纵向滚动、切换页面保留筛选。

本地验证：assembleDebug、lintDebug、7 项数据测试通过。Android 模拟器完整操作测试 1 项通过，覆盖登录、筛选、状态恢复、取消和确认续费、查看车位和退出。完整上游回归因 Google Maven 返回 503 中断，不计为通过。最后的微调包含筛选换行间距、首次未登录不显示失效错误，以及续费对话框支持滚动。

限制：未接入新增/编辑订阅、车友收款续费、仪表盘、Passkey、Turnstile；车位只读。只在隔离测试库做了写入测试，未操作生产数据。APK 使用 debug 签名和独立 debug 包名，适合试用；后续正式签名包可能需要重新安装。无通知推送。
